# Acoustic Metamaterials — Data Analysis

*Скрипты для обработки и визуализации данных акустического эксперимента по управлению диаграммой направленности динамика с помощью метаматериалов*

---

## О проекте

Проект посвящён исследованию пассивных акустических метаматериальных структур, способных изменять диаграмму направленности (ДН) и АЧХ звука, излучаемого динамиком, без использования активной электроники.

В рамках работы было проведено численное моделирование (COMSOL Multiphysics) двух типов метаструктур:
- **Структура №1** — массив элементов с анизотропным импедансом (широкополосный поворот ДН на фиксированный угол за счёт градиента фазы).
- **Структура №2** — резонансная структура на основе колец со щелями (частотно-зависимый поворот ДН, выраженные резонансы).

Для проверки результатов моделирования был проведён акустический эксперимент: динамик излучал ЛЧМ-сигнал, который записывался микрофоном по окружности (шаг 10°, 37 точек) в двух конфигурациях — с установленной структурой и без неё (свободное поле). Скрипты в этом репозитории обрабатывают именно эти экспериментальные записи.

---

## Что делают скрипты

### 1. `average_4.py` — усреднение сигнала по частоте

* Для каждого `.wav`-файла (запись под определённым углом) вычисляется БПФ.
* Из спектра выделяется узкая полоса **±1 Гц** вокруг целевой частоты, значения в этой полосе усредняются — так убирается шум и погрешности.
* Угол считывается из названия файла.
* Результат для всех углов сохраняется в `.txt` в виде пар **(угол; значение)**.

Такие `.txt`-файлы были получены для каждой интересующей частоты, парами:
- `..._str.txt` — запись **со** структурой
- `..._without_str.txt` — запись **без** структуры (референс)

### 2. `plot_polar.py` — построение диаграммы направленности

* Загружает пару файлов (со структурой / референс) для нескольких частот.
* Приводит данные к общей угловой сетке (интерполяция).
* Считает относительное изменение уровня в **дБ**: `20·log10(вклад структуры / референс)`.
* Строит полярную диаграмму направленности для выбранных частот на одном графике.
* Опционально — сглаживание (Savitzky–Golay), чтобы убрать дребезг и выделить главные лепестки.

## Как использовать

1. Указать в `average_4.py` папку с `.wav`-записями (`SOURCE_DIR`) и целевую частоту (`F_MIN`, `F_MAX`). Также изменить под себя названия файлов.
2. Запустить скрипт — на выходе получится `.txt` с парами (угол; энергия).
3. Повторить для всех нужных частот и обеих конфигураций (со структурой / без).
4. В `plot_polar.py` указать пары файлов для нужных частот (словарь `data_pairs`).
5. Запустить — построится полярная диаграмма направленности в дБ.
6. Чтобы включить сглаживание — раскомментировать строку с `savgol_filter`.

## Пример результата

Диаграмма направленности показывает, как метаструктура перераспределяет энергию излучения по углам относительно свободного поля (0 дБ = без изменений, отрицательные значения = ослабление, положительные = усиление в данном направлении).

## Замечание

Данных получилось довольно много (десятки частот × два состояния × усреднение по 4 записям), так что повторить весь пайплайн один в один будет непросто — зато структуру мы погоняли знатно 🙂 Для полного анализа эксперимента мы использовали построение диаграмм с чистыми данными, но наибольшей инетерес предсталяет анализ в дБ.
